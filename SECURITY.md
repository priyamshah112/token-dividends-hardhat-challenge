# Security

## Supported Use

This repository is a smart-contract challenge solution and has not been audited.

## Production Warning

Do not deploy this contract with real value without:

- Independent security review.
- Gas analysis for holder-count growth.
- Re-entrancy and denial-of-service review.
- Event and observability improvements.
- Comparison against audited token implementations.

## Secrets

Do not commit private keys, mnemonics, RPC credentials, deployer keys, or explorer API keys.

## Reporting

Report security concerns privately to the repository owner rather than opening a public issue with exploit details.
